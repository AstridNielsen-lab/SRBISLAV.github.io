## Пројекат Робосервис

### Опис
Репозиторијум садржи изворни код пројекта Роботрабалхо, веб апликације која користи вештачку интелигенцију за пружање виртуелне помоћи у реалном времену. Систем интегрише ОпенАИ платформу за генерисање аутоматских одговора и Мицрософт Азуре за претварање текста у аудио.

### Инсталација

Да бисте инсталирали и покренули локално, следите доле наведене кораке:

1. **Клонирајте спремиште:**
   ```bash
   git clone https://github.com/AstridNielsen-lab/SRBISLAV.github.io.git
   cd SRBISLAV.github.io
   ```

2. **Инсталирајте Питхон зависности:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Конфигурација АПИ кључа:**
   - Obtenha uma chave de API da OpenAI e configure-a no arquivo `app.py`.
   - Obtenha uma chave de API do Azure Speech e configure-a no arquivo `app.py`.

4. **Покрените Фласк сервер:**
   ```bash
   python app.py
   ```

5. **Приступ прегледачем:**
   Abra seu navegador e vá para `http://localhost:5000`.

### Предуслови
- Python 3.x instalado
- Contas e chaves de API da OpenAI e Microsoft Azure
